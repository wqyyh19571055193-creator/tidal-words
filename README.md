# 潮汐词笺

鸣潮主题的英语单词学习网页，内置四级词库、双向四选一练习、间隔复习、学习记录，以及守岸人、绯雪、爱弥斯、达妮娅的角色立绘与点击语音。

此目录可直接作为 GitHub Pages 发布根目录，无需构建。仓库 Settings → Pages → Deploy from a branch → main → / (root) → Save。

当前为游客模式，进度保存在浏览器中。邮箱注册和跨设备同步尚未启用；auth-config.js 的 Supabase 配置为空。

非官方个人学习项目，角色立绘及语音版权归库洛游戏。语音来源见 voices/sources.json，立绘来源为 wuthering.gg。四级词库来自 KyleBing/english-vocabulary，许可见 VOCAB-LICENSE.txt。
